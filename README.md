# 📊 Sales and Profit Analysis Dashboard

## Project Overview

This project is an interactive **Sales and Profit Analysis Dashboard** developed using **Microsoft Excel**. The dashboard analyses sales and profit performance across different regions, markets, customer segments, and product categories.

The project was completed as part of my **Data Analytics Training Programme** to develop practical skills in data analysis, data visualization, and dashboard development.

## 🎯 Objectives

The main objectives of this project were to:

* Analyse sales performance across different regions and markets.
* Analyse profit generated by different regions.
* Compare sales performance across customer segments.
* Analyse profitability across product categories.
* Build an interactive and user-friendly Excel dashboard.
* Transform raw data into meaningful business insights.

## 🛠️ Tools & Technologies

* **Microsoft Excel**
* **Pivot Tables**
* **Pivot Charts**
* **Slicers**
* **Data Cleaning & Preparation**
* **Data Analysis**
* **Data Visualization**

## 📈 Dashboard Features

The dashboard provides visual analysis of:

* 💰 Profit by Region
* 📊 Sales by Region
* 👥 Profit by Customer Segment
* 📈 Sales by Customer Segment
* 🗂️ Profit by Product Category

### Interactive Filters

Users can interact with the dashboard using slicers to filter the analysis by:

* Market
* Region
* Category
* Segment

## 🔍 Business Insights

The dashboard can be used to identify:

* Which regions generate the highest sales.
* Which regions are the most profitable.
* Which customer segments contribute the most sales and profit.
* Which product categories generate the highest profit.
* Differences in sales and profitability between markets and regions.
